# Git Auto-Push Rule

Whenever you complete a requested coding task, or after the user accepts and you execute an implementation plan, you MUST automatically commit and push the changes to GitHub.

Workflow:
1. Run `git add .`
2. Run `git commit -m "<descriptive message of the changes>"`
3. Run `git push origin main`

Do this proactively at the end of your workflow without asking the user for permission to push.
